# グニャマスト — かぐや、月へ帰る。

迎えが来ない。なら、登ろう。

ぐにゃぐにゃのかぐや姫を操作して、竹を伝って月へ帰るスマートフォン向けの3Dブラウザゲームです。**24m先の月までの帰還タイム**を競います。竹と主人公はThree.jsの立体モデルで、主人公は竹に顔を向けた後ろ姿です。

[ゲームで遊ぶ](https://cadmium2525.github.io/climbing-the-mast/) · [リポジトリー](https://github.com/cadmium2525/climbing-the-mast)

## 遊び方

1. 「自力で、月へ帰る」を押すと計測開始。
2. 左右の手足の丸を、少し上の竹へゆっくりドラッグします。
3. 手足が追いついてから離すと、竹をつかみ直します。
4. **手→足→手→足**と交互に高い位置へつかみ直すと、4回で**羽衣の追い風**が発生。0.8m上へ進めます。左右の順序は自由です。

マウス、または手足ボタンを選択して矢印キーとEnterでも操作できます。少なくとも2本、慣れるまでは3本の手足を竹に残すのがコツ。つかみ直すだけでは追い風は発生せず、高い位置へ運ぶ必要があります。

制限時間はありません。速く帰れたタイムが記録になります。一時停止・遊び方を開いている間と、タブが非表示の間は時計も止まります。月に到着するとタイムが確定します。

## 道中の楽しみ

- **近づく月と5つの景色**: 竹取の里→山鳥の便り→雲の渡し→天の川→月の庭。
- **月で待つ家族**: 月の父と母が手を振ってお出迎え。月うさぎも一緒に、かぐや姫の帰還を待っています。
- **短い物語**: 区間を越えると、かぐや姫や月うさぎの便りが届きます。操作を止めるダイアログは開きません。
- **手足のリズム**: 速さだけでなく、手と足を交互に運ぶ判断が近道になります。
- **休み竹**: 6m / 12m / 18mに中継地点。落ちても月うさぎに救出され、最後の地点から復帰します。救出1回につき帰還タイムに5秒加算します。
- **自己ベストとの競争**: 2回目以降は、区間の到達タイムを自分の最速記録と比較できます。
- **帰還カード**: タイム・称号・追い風回数・救出回数をまとめたPNGを保存して共有できます。

24mはおとぎ話のコース内での距離です。

## 記録とSNS

「記録をシェア」は対応端末の共有画面を開きます。PNGのファイル共有に対応していない場合は、投稿文やURLの共有、またはカード保存に切り替わります。「Xに投稿する」は記録とゲームURLを入れた投稿画面を開きます。画像も載せる場合は保存したカードを添付してください。投稿の確定はプレイヤーが行います。

最速帰還タイムと区間タイムは端末の`localStorage`に保存します。**月まで到着した記録だけ**が自己ベストの対象で、途中リタイアは含みません。旧版の高さ記録とは別に保存します。全国ランキングやアカウント機能はなく、ブラウザーのデータを消すと記録も消えます。

## 起動・ビルド

Node.js 22.12以上とnpmを用意し、このフォルダーで実行します。

```sh
npm ci
npm run dev
```

表示されたURLをブラウザーで開きます。同じWi-Fiのスマートフォンからは、表示されるNetworkのURLで確認できます。

```sh
npm test
npm run build
npm run preview
```

`npm test`はぐにゃぐにゃの操作に加え、月への帰還、追い風、タイムの確定、救出ペナルティなどを検証します。`npm run build`は型検査と静的サイトの生成を行い、出力先は`dist/`です。APIキーや環境変数は不要です。

## GitHub Pages

このリポジトリーはGitHub PagesのGitHub Actions公開を設定済みです。`main`へpushすると、`.github/workflows/deploy.yml`が依存取得→テスト→ビルド→公開を行います。[Actions](https://github.com/cadmium2525/climbing-the-mast/actions)で状況を確認できます。

別のリポジトリーで公開する場合はPublicにして、Settings → Pages → SourceをGitHub Actionsに設定してください。`vite.config.ts`は`base: './'`なので、リポジトリー名のサブディレクトリーでも動きます。

## 費用・素材・構成

ゲームはブラウザー内で完結し、有料API・サーバー・データベースは不要です。[PublicリポジトリーのGitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site)と[標準ランナーのGitHub Actions](https://docs.github.com/en/actions/concepts/billing-and-usage)で公開できます。独自ドメインの購入も不要です。

3Dモデル・月・装飾はコードから生成し、有料モデルやフォントを使用していません。背景は本プロジェクト用に生成したローカル画像です。実行中の画像生成や課金API呼び出しはありません。[背景の記録](public/assets/ASSETS.md)、[Three.jsのライセンス](public/THIRD-PARTY-NOTICES.txt)も同梱しています。

主なソース: `simulation.ts`（操作と身体）、`race.ts`（帰還レース）、`renderer.ts`（3D描画）、`ui.ts` / `style.css`（画面）、`share.ts`（カード）、`biomes.ts`（景色）。いずれも`src/`内です。[動作確認メモ](docs/verification.md)に検証範囲を記録しています。
